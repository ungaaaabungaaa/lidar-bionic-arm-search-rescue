# Bench contract v1

The model is a fixed four rotation joint arm: base yaw, shoulder pitch, elbow pitch, wrist pitch. Link lengths are0.30,0.25,0.10m; shoulder height 0.15 m. Link radii are0.025,0.022,0.020m and the hand is a 0.035 m sphere/coupled-gripper proxy. This is not a physical five-finger mechanism. All coordinates are metres in a right-handed base frame, z up. Angles are radians. Tool pitch is the sum of the three pitch joints.

Cloud JSON has exactly version1, frame `lidar`, units `m`, `sensorToBase` (row-major3×3 proper rotation and translation[3]) and points[xyz]. Maximum10000points and2MiB input JSON; every component is finite and within±5m. Rotation rows must be orthonormal and determinant+1 within 1e-6. Processing removes points outside a fixed bench region/known ground threshold, voxelizes at 0.01 m and extracts Euclidean connected components with0.035m tolerance. Neighbor work is bounded to1million comparisons. Cluster size/bounds determine candidate eligibility; this is not semantic person/victim detection. Partial visible bounds do not establish complete object geometry.

A candidate reach target is the observed horizontal centre and observed top+0.12m stand-off, with tool pitch-π/2. IK evaluates both elbow branches and joint limits. Planning uses separately supplied conservative obstacle AABBs (at most12, finite bounded coordinates), not a claim that unobserved space is safe. Collision checks cover link capsules, a hand sphere, floor and a base fixture, plus nonadjacent self collision. Direct and staged high-lift paths precede a seeded bounded bidirectional RRT fallback. Outcomes distinguish planned, unreachable, goal/start collision and planning budget; failed results contain no executable trajectory.

Joint interpolation is certified with a global displacement bound B=0.65(|Δyaw|+|Δshoulder|)+0.35|Δelbow|+0.10|Δwrist|. Midpoint checks on n=ceil(B/0.008m) subintervals inflate every link radius by B/(2n), conservatively covering the full interpolation. Limit512subintervals per edge,25000pose evaluations,1000RRTnodes and1000iterations. A final accepted path is checked again. No endpoint-only safety claim is allowed.

Quintic s=10u³-15u⁴+6u⁵ gives zero velocity/acceleration at each waypoint. Segment duration uses peak derivative1.875 and peak second derivative5.773503 with joint limits1rad/s and2rad/s², rounded up to dt0.05s. This is a kinematic reference, not torque/contact/force control. Bound64waypoints,3001frames and3MiB serialized report. The gripper and object contact are not simulated.

The J1 text control interface quantizes four joint targets to milliradians and gripper opening to millimetres. It includes sequence0..65535, A/M/S state request, lease100..500ms and CRC8poly 0x07. A safety-latch emulator starts with no output, requires explicit ARM at the known current pose, rejects malformed/stale/oversized data, and drops output on lease expiry or STOP. It never opens a device. No MCU firmware or real servo/LiDAR driver is shipped; physical hardware needs its own reviewed controller, feedback, limit switches and independent stop.

The CLI/library `occluded` scene adds a wide front panel that hides the small target. It yields observed panel returns and no eligible small candidate, so no reference is emitted. At zero simulated noise, panel+object and panel-only scans match exactly. This case demonstrates partial-observation limits; no free-space or object-absence conclusion may be made behind the first surface. The fixed12run reproduction covers the original four scenes; the new scene has separate regression checks across seeds1–3.
